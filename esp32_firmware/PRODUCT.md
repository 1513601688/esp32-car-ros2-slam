# Product

## Register

product

## Users

Robotics builders and operators using an ESP32-based omni wheel chassis from a phone, tablet, or laptop while testing motors, encoders, IMU data, and ROS serial integration.

## Product Purpose

Provide a compact live dashboard for monitoring chassis telemetry and controlling core calibration actions without interrupting ROS control. Success means the operator can trust connection state, encoder pulses, IMU readings, and odometry at a glance.

## Brand Personality

Precise, technical, composed.

## Anti-references

Avoid toy-like mobile game controls, decorative sci-fi panels that reduce readability, and generic dark dashboard blocks with weak hierarchy.

## Design Principles

Prioritize live telemetry clarity over decoration.
Keep control actions visually distinct from passive readings.
Make the interface usable on a phone beside the robot and on a desktop during debugging.
Use restrained motion only to communicate connection and state changes.
Preserve the existing hardware control behavior.

## Accessibility & Inclusion

Target readable contrast for small telemetry labels and values. Respect reduced motion preferences. Avoid relying on color alone for connection state.
